# Идеи итогового проекта

## 1. Сортировщик учебных заметок

Пользователь — студент, который быстро записывает задания и напоминания. Он вводит короткую заметку, а модель выбирает одну категорию: `учёба`, `быт` или `другое`. Программа на C++ проверяет категорию и сохраняет заметку в соответствующий текстовый файл.

Первая версия принимает одну заметку и показывает выбранную категорию. Если модель вернула другое слово, программа сообщает об ошибке и ничего не сохраняет.

Примеры проверки:

- `Подготовить доклад по C++` → `учёба`;
- `Купить молоко` → `быт`;
- `Позвонить преподавателю вечером` → пограничный пример, результат нужно подтвердить у пользователя.

## 2. Помощник по простым ошибкам C++

Пользователь — начинающий программист. Он вводит короткое сообщение компилятора и несколько строк кода. Модель объясняет ошибку простыми словами. Программа ограничивает размер ввода, отправляет запрос и показывает ответ, но не изменяет файлы автоматически.

Первая версия работает с одной ошибкой, например с пропущенной точкой с запятой. Результат считается полезным, если в нём названа причина и предложено исправление, которое проходит компиляцию. При неверном или слишком общем ответе пользователь видит исходное сообщение компилятора и предупреждение.

Примеры проверки:

- пропущена `;` после объявления переменной;
- забыто `#include <iostream>`;
- `undefined reference` из-за отсутствующего `.cpp` — более сложный пограничный пример.

## Модели-кандидаты

1. [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/tree/main) — GGUF Q4_K_M, около 469 МиБ. Поддерживает русский язык, быстро работает на CPU и подходит для классификации и коротких объяснений.
2. [Qwen2.5-Coder-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-Coder-0.5B-Instruct-GGUF/tree/main) — GGUF Q4_K_M, около 491 МБ. Лучше подходит для сообщений компилятора и небольших фрагментов C++.
3. [SmolLM2-360M-Instruct](https://huggingface.co/bartowski/SmolLM2-360M-Instruct-GGUF/tree/main) — GGUF Q4_K_M, около 271 МБ. Требует меньше памяти, но хуже работает с русским языком, поэтому подходит как запасной вариант.
