# Урок 7 — Pirogov

Это простая программа на C++, которая сортирует массив целых чисел.
Для сортировки используется пузырьковый метод.

## Файлы

- `main.cpp` — программа сортировки;
- `CMakeLists.txt` — настройка сборки CMake;
- `opencode.jsonc` — настройки OpenCode без секретного ключа;
- `README.md` — описание и команды для проверки.

## Что делает программа

В программе есть массив:

```text
7 2 9 1 5 3 8
```

Соседние элементы сравниваются друг с другом. Если левое число больше
правого, они меняются местами. Проходы повторяются, пока массив не будет
отсортирован.

## Сборка

Откройте терминал в каталоге `assignments/lesson07/pirogov` и выполните:

```bash
cmake -S . -B build
cmake --build build --config Debug
```

Запуск на Windows:

```powershell
.\build\Debug\sort_array.exe
```

Запуск на Linux:

```bash
./build/sort_array
```

## Проверенный результат

```text
Before sorting: 7 2 9 1 5 3 8
After sorting:  1 2 3 5 7 8 9
```

## Проверка через OpenCode

Проект также проверен через OpenCode 2.2.0 и модель `msu/qwen38_27b`.
Агент прочитал файлы проекта и сначала попробовал использовать CMake. В WSL
CMake не был установлен, поэтому агент выполнил более простую команду:

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o /tmp/opencode/sort_array
/tmp/opencode/sort_array
```

Компиляция прошла без предупреждений. Вывод совпал с результатом выше.
OpenCode решил, что исправления не нужны, и не изменил исходные файлы.

## Как повторить работу через OpenCode

В каталоге проекта есть `opencode.jsonc`. В нём нет секретного ключа: OpenCode
получает его из переменной окружения `MSU_API_KEY`.

В WSL ключ можно безопасно ввести так, чтобы он не остался в истории команд:

```bash
read -s -p "MSU API key: " MSU_API_KEY
export MSU_API_KEY
echo
```

После этого можно запустить `opencode --standalone` и отправить такой запрос:

```text
Создай простую программу на C++, которая сортирует массив целых чисел
пузырьковым методом. Используй обычные циклы и временную переменную.
Добавь CMakeLists.txt. Собери программу, запусти её и проверь результат.
Не используй сложные конструкции.
```

После работы агента нужно самостоятельно посмотреть изменения:

```bash
git diff
```

Также надо проверить каждую команду, которую предлагает выполнить агент.

После завершения OpenCode переменную с ключом надо удалить:

```bash
unset MSU_API_KEY
```
